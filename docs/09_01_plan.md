TreeBench-Adaptive OPD-Aha：面向状态选择性视觉干预的 On-Policy Distillation 设计草案

目标：在 不增加 Teacher 数量、不使用 ground-truth answer / option 信息、不使用 question 条件标签、不做 K-sampling / Best-of-N 的前提下，将 OPD-Aha 适配到 TreeBench。
核心思路不是继续更换 privileged information，而是让模型学习：在什么状态下应该信任并放大 hide+GT-crop 带来的视觉干预，什么时候不应该放大。

1. 背景与问题定义

1.1 原始 privileged OPD / OPD-Aha 的基本形式

在标准 privileged OPD 中：

Student 在原始视觉输入上进行 on-policy rollout；

Teacher 在相同 Student prefix 下，获得更丰富的视觉信息；

Teacher 的 token distribution 被直接蒸馏给 Student。

OPD-Aha 的关键修改是：
同一个 Teacher 在两个 matched visual conditions 下做前向计算：

evidence-present view；

evidence-absent / visual-null view。

记：

[
p_t^+(v) = p_\phi(v \mid I^+, h_t),
]

[
p_t^0(v) = p_\phi(v \mid I^0, h_t),
]

其中 (h_t=(x,y_{<t})) 为 Student 生成的共享 prefix。

定义 evidence-induced token preference：

[
u_t(v)=\log p_t^+(v)-\log p_t^0(v).
]

原始 OPD-Aha 构造：

\frac{
p_t^+(v)\exp(\beta u_t(v))
}{
\sum_w p_t^+(w)\exp(\beta u_t(w))
},
]

等价于：

[
q_t=
\operatorname{softmax}
\left(
(1+\beta)\log p_t^+
-\beta\log p_t^0
\right).
]

其解释是：
以 privileged Teacher (p_t^+) 为 anchor，沿 same-Teacher real-vs-null 的视觉方向进行重构，从而恢复被 Student prefix 压制的 visual correction。

原始论文进一步给出一个 KL-regularized interpretation：

D_{\mathrm{KL}}(q\Vert p_t^+)
\right].
]

因此，(\beta) 可以理解为“沿视觉残差方向离开标准 privileged target 的强度”。

2. TreeBench 上目前的经验发现

以下内容来自当前对 TreeBench hide 设置的分析，而不是 OPD-Aha 原论文中的结论。

2.1 早期 reasoning divergence 很普遍，但与最终 outcome 并不稳定相关

当前观察：

前约 300 字的 reasoning Jaccard 只有约 0.30–0.41；

405 对样本中约有 80 对发生最终答案翻转；

但 reasoning 内容替换本身非常普遍；

只有当被替换的事实恰好是 decision-relevant 时，才会影响最终 answer。

这说明：

privileged view 改变 reasoning 文本，不等于 privileged view 暴露了 correction。

因此，不能简单把所有 hide-vs-full 的 token distribution discrepancy 都等强放大。

2.2 hide 并不会显著增加 GT object mention，而是改变感知表述基底

观察到：

hide 并没有让模型更多显式提及 GT object；

某些情况下反而更少；

mask 剥掉外观线索后，模型可能改用形状、位置、结构性描述重命名对象；

例如：

blue trash can

变成

a dark cylindrical object with horizontal slats

GT object 首次 mention 位置也可能更靠后。

这说明 hide 的作用不一定是“让模型更 grounding”，而可能是：

改变模型编码同一个视觉对象时所使用的 perceptual basis。

因此，hide-induced residual 中可能混有大量：

lexical re-parameterization；

visual basis replacement；

object re-description；

这些不一定与最终 TreeBench decision 有关。

2.3 hide 可能逼出更多补偿性推断

当前错误链分析表明：

在错误 reasoning group 中，hide 反而可能出现更多“编造 / 推断”标记；

视觉证据被遮掉后，模型会尝试用语言推理补偿缺失信息。

可以概括为：

mask 逼出更多推理；
遮掉的是误导源时可能受益；
遮掉的是必要证据时可能受害。

因此：

[
\text{large hide effect}
\not\Rightarrow
\text{useful correction}.
]

2.4 很大一部分错误对 visual intervention 免疫

当前观察：

约 63% 的错误样本在两种视图下仍给出相同错误答案；

perspective 子集中约 48/85 两种视图同时错误；

这类样本对 hide / full 等视觉干预表现出较强 invariance。

这意味着，在以下约束下：

不使用 GT answer；

不使用 option label；

不增加第三个 Teacher；

不进行额外 sampling；

如果：

[
p^H \approx p^F
]

且二者最终都错，那么方法本身并没有足够的信息凭空恢复“正确方向”。

因此，合理目标不是强行纠正这类状态，而是：

识别它们不是可靠的 privileged-correction state，并避免过度放大无效监督。

3. TreeBench-specific 方法动机

3.1 核心区别

原始 OPD-Aha 隐含一个较强假设：

real-vs-null residual 在大多数位置都可以看作值得放大的 visual correction。

而 TreeBench 当前现象表明：

u_t^{\text{rephrase}}
+
u_t^{\text{missing-evidence}}
+
u_t^{\text{decision}}.
]

即 hide-induced residual 可能混合：

表述重构

证据缺失后的补偿性推理

真正 decision-relevant 的 correction

因此 TreeBench adaptation 的核心应当是：

不是设计新的 privileged information，而是设计 state-selective reconstruction。

4. 建议方法：State-Adaptive OPD-Aha

4.1 视觉输入设置

Student view

Student 始终使用原始 full image：

[
I^S = I^{F}.
]

Teacher privileged view

当前主设置：

[
I^H = \text{hide + GT crop}.
]

这是当前 empirically 最优的 privileged information。

Teacher reference view

建议主方法使用：

[
I^F = \text{full image}.
]

即同一个 frozen Teacher 分别看：

hide+GT-crop；

full image。

不引入第三个 Teacher。

4.2 三个核心分布

对 Student rollout 的第 (t) 个位置：

[
h_t=(x,y_{<t}).
]

定义：

T(v\mid I^H,h_t),
]

T(v\mid I^F,h_t),
]

S(v\mid I^F,h_t).
]

其中：

(T)：frozen Teacher；

(S)：trainable Student；

所有分布共享同一个 Student-generated prefix。

4.3 Hide intervention residual

定义：

\log p_t^H(v)-\log p_t^F(v).
]

这里的 (u_t) 不再解释为“visual present vs absent”，而解释为：

hide+crop intervention 相对于模型正常 full-image perception 改变了哪些 token preference。

5. 第一项：Masked / Hidden Intervention Effect

为了避免和图像操作中的 hide 混淆，推荐命名为：

Excess Privileged Effect

Masked Intervention Effect

Unexpressed Intervention Effect

而不要直接叫 hidden effect。

定义：

D_{\mathrm{JS}}(p_t^H,p_t^F)

\lambda
D_{\mathrm{JS}}(p_t^H,p_t^S).
]

默认可先取：

[
\lambda=1.
]

再做截断：

[e_t]_+.
]

5.1 直觉

第一项：

[
D_{\mathrm{JS}}(p_t^H,p_t^F)
]

衡量：

hide+crop 对同一个 Teacher 改变了多少。

第二项：

[
D_{\mathrm{JS}}(p_t^H,p_t^S)
]

衡量：

标准 privileged OPD 当前已经能看到多少 Teacher–Student discrepancy。

因此，如果：

[
p_t^H \approx p_t^S
]

但：

[
p_t^H \not\approx p_t^F,
]

说明：

Student 和 privileged Teacher 表面已趋于一致，但 privileged intervention 本身仍显著改变 Teacher 的内部 token preference。

这类 state 更值得进行额外 reconstruction。

5.2 示例

假设 next-token 只有三个主要候选：

token

(p^H)

(p^F)

(p^S)

left

0.65

0.25

0.60

right

0.15

0.55

0.20

continue

0.20

0.20

0.20

此时：

(p^H) 和 (p^S) 很接近；

standard OPD 会认为 Teacher–Student gap 已很小；

但同一个 Teacher 在 hide 和 full 下明显发生 decision shift。

因此：

[
D_{\mathrm{JS}}(H,F)
\gg
D_{\mathrm{JS}}(H,S).
]

于是：

[
e_t \gg 0.
]

说明这个位置存在“standard OPD 没有显式捕捉到的 privileged intervention effect”。

5.3 不建议只用 (D(H,F))

因为当前 TreeBench 已观察到：

hide 会改变 object naming；

会改变描述方式；

会产生与最终 answer 无关的 lexical divergence。

所以：

[
D(H,F)\text{ 大}
]

本身不足以证明这个 state 值得被强监督。

6. 第二项：Privileged Sharpening

定义：

H(p_t^F)-H(p_t^H).
]

其中 (H(\cdot)) 是 entropy。

6.1 含义

如果：

[
s_t>0,
]

则：

[
H(p_t^H)<H(p_t^F),
]

说明 hide+crop 让 Teacher 的 next-token distribution 更集中。

可以理解为：

privileged intervention 让 Teacher 在当前 state 下变得更确定。

6.2 示例 A：hide 去掉 distractor

full image：

[
p^F=[0.35,0.30,0.20,0.15].
]

hide+crop：

[
p^H=[0.70,0.10,0.10,0.10].
]

此时：

[
H(p^H)<H(p^F),
]

因此：

[
s_t>0.
]

这种 state 更像：

hide 去掉了 distracting evidence，使 Teacher 的 local belief 被 sharpen。

6.3 示例 B：hide 去掉必要 context

full image：

[
p^F=[0.75,0.10,0.10,0.05].
]

hide+crop：

[
p^H=[0.35,0.30,0.20,0.15].
]

此时：

[
H(p^H)>H(p^F),
]

因此：

[
s_t<0.
]

这更像：

privileged intervention 移除了必要证据，Teacher 开始产生补偿性推断与不确定性。

6.4 注意：Sharpening 不是 correctness

即使：

[
p^H=[0.95,0.03,0.02]
]

也可能 0.95 对应错误 token。

所以 sharpening 不能被当作“是否正确”的 detector。

更合理的是：

只把 sharpening 作为 budget modifier，而不是 hard gate。

例如：

c_{\min}
+
(1-c_{\min})
\sigma
\left(
\frac{s_t-\tau_s}{T_s}
\right).
]

推荐：

[
c_{\min}\in[0.3,0.5].
]

这样 (s_t<0) 时不会完全停止监督，只会降低额外 reconstruction 强度。

7. 第三项：Re-entry Window

7.1 动机

如果每个 token 都完全独立地决定是否 reconstruction，可能出现：

token t      strong intervention
token t+1    weak
token t+2    weak
token t+3    almost zero

这会导致：

Student 只被推离原 reasoning 一下，但没有足够时间完成视觉重新检查和 reasoning revision。

例如：

... so the object must be on the person's right.
wait,
...

如果下一 token 立即关闭额外 correction，Student 可能又回到原来错误 trajectory。

7.2 定义

先得到 raw gate：

[
g_t^{raw}.
]

然后引入 temporal persistence：

\max
\left(
g_t^{raw},
\rho g_{t-1}
\right),
]

其中：

[
0<\rho<1.
]

例如：

[
\rho=0.90.
]

如果某个位置：

[
g_t^{raw}=0.90,
]

后面 raw gate 很快下降，则：

position      raw gate     re-entry gate
t               0.90           0.90
t+1             0.25           0.81
t+2             0.10           0.73
t+3             0.08           0.66
t+4             0.05           0.59
...

这样一个视觉冲突 state 可以打开一个约 8–16 token 的持续 correction window。

7.3 为什么这适合 Qwen3.5-VL

当前 Qwen3.5-VL 的特点是：

grounding / reconsideration 是偶尔 emergent；

并不是经过 SFT 强制形成 ground -> reason -> answer protocol；

hide privilege 反而能和这种 emergent reasoning 配合。

因此不应该用：

wait

look again

bbox token

grounding token

作为显式触发条件。

更适合的是：

distributional conflict 触发 re-entry，而不是 lexical token 触发 re-entry。

8. Adaptive KL Budget

8.1 从固定 (\beta) 改为 state-adaptive budget

先定义 intervention gate：

\sigma
\left(
\frac{
e_t^+-\tau_e
}{
T_e
}
\right).
]

定义 sharpening modifier：

c_{\min}
+
(1-c_{\min})
\sigma
\left(
\frac{s_t-\tau_s}{T_s}
\right).
]

得到：

a_t c_t.
]

再加入 re-entry：

\max
\left(
g_t^{raw},
\rho g_{t-1}
\right).
]

最终：

\epsilon_{\max}g_t
}
]

8.2 用 KL budget 求 (\beta_t)

对每个 token position，定义：

\operatorname{softmax}
\left(
\log p_t^H
+
\beta u_t
\right).
]

然后求：

\epsilon_t.
]

8.3 为什么不是直接预测 (\beta_t)

KL budget 的优点：

(\epsilon_t) 有直观含义：

“允许 target 离开 privileged Teacher 多远”

与原 OPD-Aha Appendix 的 constrained interpretation 一致；

不同 token position 的 residual magnitude 不同，直接固定 (\beta) 的可比性较弱；

adaptive budget 更容易解释为：

强 intervention state：允许更大 target move；

弱 / 可疑 state：保持更接近 standard OPD。

8.4 (\beta_t) 的求解成本

不需要 gradient descent。

因为：

[
D_{\mathrm{KL}}(q_t(\beta)\Vert p_t^H)
]

随 (\beta) 单调不减。

可直接进行 6–8 次 binary search：

beta_low  = 0
beta_high = beta_max

repeat 6~8 times:
    beta = (beta_low + beta_high) / 2
    q = softmax(log_pH + beta * u)
    kl = KL(q || pH)

    if kl < epsilon_t:
        beta_low = beta
    else:
        beta_high = beta

如果分布 support 使用 top-100 + tail bucket，则每个 token 只在约 101 个数上进行若干次向量运算。

这部分计算通常远小于两次 Teacher forward。

9. 最终 target 与训练目标

最终 target：

\operatorname{softmax}
\left(
\log p_t^H
+
\beta_t
(\log p_t^H-\log p_t^F)
\right).
]

然后沿用原 OPD-Aha / Vision-OPD 的 token-level divergence。

如果使用 JSD：

\frac12 p_t^S+\frac12 q_t,
]

\frac12
D_{\mathrm{KL}}(p_t^S\Vert m_t)
+
\frac12
D_{\mathrm{KL}}(q_t\Vert m_t).
]

最终：

\frac{
\sum_t M_t\ell_t
}{
\sum_t M_t
}.
]

这样可以最大程度排除：

因此 paper claim 可以更干净：

13. Training Pipeline

for each batch:

    # 1. Student rollout
    y ~ Student(image_full, question)

    # 2. Student token distributions
    p_S = Student(image_full, question, prefix=y_<t)

    # 3. Same frozen Teacher, two views
    p_H = Teacher(image_hide_crop, question, prefix=y_<t)
    p_F = Teacher(image_full, question, prefix=y_<t)

    # 4. Hide intervention residual
    u = log(p_H) - log(p_F)

    # 5. Excess intervention effect
    e = JS(p_H, p_F) - lambda * JS(p_H, p_S)
    e = relu(e)

    # 6. Privileged sharpening
    s = H(p_F) - H(p_H)

    # 7. Raw gate
    a = sigmoid((e - tau_e) / T_e)
    c = c_min + (1 - c_min) * sigmoid((s - tau_s) / T_s)
    g_raw = a * c

    # 8. Re-entry window
    g_t = max(g_raw_t, rho * g_(t-1))

    # 9. Adaptive KL budget
    epsilon_t = epsilon_max * g_t

    # 10. Solve beta_t
    beta_t = binary_search(
        KL(q(beta) || p_H) = epsilon_t
    )

    # 11. Target reconstruction
    q_t = softmax(
        log(p_H) + beta_t * (log(p_H) - log(p_F))
    )

    # 12. Distillation loss
    loss = JSD(p_S, q)

14. 推荐 Probing 设置

Probing 的主要目标不是“再证明 accuracy 高”，而是回答：

adaptive method 到底有没有学会区分
useful privileged intervention
和
mere view-induced rewriting / harmful masking。

Probe A：Gate 与 trajectory position

记录每个样本沿 trajectory 的：

[
g_t,\ e_t,\ s_t,\ \beta_t.
]

画：

normalized trajectory position
vs
mean gate / beta / epsilon

需要观察：

是否不是从开头就一直很大；

是否更集中于中后期 reasoning conflict；

是否和最终 revision 位置对应。

Probe B：Gate 与 lexical divergence

对 full / hide response 做：

rolling Jaccard；

sentence-level semantic similarity；

token-edit distance。

然后比较：

high lexical divergence + low gate
high lexical divergence + high gate

理想结果：

大量仅仅改变 wording 的位置不应该自动获得高 gate。

这直接验证 observation 1 和 2。

Probe C：Gate 与 object mention

统计：

GT object first mention position；

object mention frequency；

visual descriptor type；

shape / color / spatial descriptor shift。

比较：

high gate states
vs
low gate states

目标不是证明 high gate 一定更多提 GT object，而是：

high gate 是否更接近 decision-relevant transition，而非单纯 object renaming。

Probe D：Sharpening 是否抑制 harmful hide

对已有分析中的两类样本：

full wrong -> hide correct
full correct -> hide wrong

做 post-hoc probing。

注意：
这些 group 只能用于 evaluation / analysis，不进入训练。

比较：

[
s_t
]

在两组中的分布。

理想现象：

hide-beneficial group 中更常见 (s_t>0)；

hide-harmful group 中更常见 (s_t<0) 或较低。

如果两者完全不可分，则 sharpening 不应作为核心 component。

Probe E：Re-entry 是否产生持续 revision

找到首次：

[
g_t > \tau_g
]

的位置 (t^*)。

比较后续：

1–8 tokens
9–16 tokens
17–32 tokens
33–64 tokens

中的：

(D(p^S,p^H))

(D(p^S,p^F))

Student token 对 (u_t) 的 alignment

visual support proxy

reasoning semantic drift

理想现象：

re-entry trigger 后，Student 不只是单 token 改变，而是在后续 8–32 token 中持续向 privileged visual direction 移动。

Probe F：Same-wrong / intervention-immune states

对：

full wrong + hide wrong

尤其是 perspective subgroup，检查：

[
D(H,F),\ e_t,\ g_t,\ \beta_t.
]

理想结果：

如果两种 view 都无法改变 Teacher，adaptive method 应该自动给低 budget，而不是强 extrapolate。

这可以成为方法的一个重要“知道什么时候不该修”的机制结果。

Probe G：Gate calibration

[0, .1)
[.1, .2)
...
[.9, 1.0]

answer flip rate；

hide-harmful rate；

reasoning revision rate。

如果 high-gate bin 明显富集：

full wrong -> hide correct

而不是：

full correct -> hide wrong

则 gate 有机制意义。

19. 计算成本估计

额外成本主要来自：

Teacher(H) forward；

Teacher(F) forward。

而 adaptive 部分：

JSD；

entropy；

EMA / max-decay；

top-k vector binary search；

KL；

都只是小规模 token-distribution 运算。

如果沿用 top-100 + tail bucket support，则每个 position 的 adaptive beta search 只在约 101 维分布上进行。

因此整体训练成本相对于“双 Teacher-view forward”增加通常较小。

20. 推荐主论文叙事

可以把方法故事压缩为：

TreeBench 中的 privileged visual information 并非 uniformly better evidence。
hide+crop 有时去除 distractor、暴露 decision-relevant cue，有时则移除必要 context，并诱发补偿性推断。
因此 fixed-strength privileged reconstruction 会同时放大 useful correction 与 harmful / representational intervention。
我们提出 state-adaptive privileged reconstruction：利用 same-Teacher hide-vs-full discrepancy、privileged sharpening 与短期 re-entry persistence，自适应决定每个 Student-visited state 的 KL reconstruction budget。
该方法不依赖 answer label、question option、grounding supervision 或 additional sampling，并保持 Teacher 与 Student 的初始 grounding capability 对齐。

23. 与当前 OPD-Aha 稿件的关系

本方案保留原 OPD-Aha 的几个核心结构：

Student-generated on-policy trajectory；

frozen same-model Teacher；

same-prefix within-Teacher visual contrast；

log-probability residual；

reconstructed target；

token-level distillation；

KL-regularized target interpretation。

主要修改点是：

从 fixed global reconstruction strength
改为
TreeBench-specific state-adaptive reconstruction budget。

原 OPD-Aha 中，较大的固定 (\beta) 用于增强 late-prefix hidden visual correction；而这里进一步假设：

在 TreeBench 中，privileged intervention 本身具有 state-dependent reliability，因此不仅 correction magnitude 随 prefix 变化，correction trustworthiness 也随 state 变化。

这就是这版 adaptation 最核心的方法论差异。

## 附录:训练前组件验证结果与方法修订(2026-09-02,probe_state_adaptive.py)

对 185 条 Qwen3.5-9B 失败链(nothink, TreeBench)做的两项组件验证,
外加实现过程中发现的一个结构性质。数据: eval/model_answer/treebench/qwen3.5-9b-stateadapt.jsonl。

### A. e_t 的自举性质(实现时发现)

训练起点 student ≡ frozen teacher 且同看 full image ⇒ p^S ≡ p^F ⇒
λ=1 时 e_t = D(H,F) − D(H,S) ≡ 0。
方法在起步阶段自动退化为标准 privileged OPD,gate 随 student 漂移逐渐打开。
处理:①作为特性写进方法解释;②训练时记录 e_t 增长曲线作为诊断量;
③若希望提前开门可设 λ<1(消融项)。

### B. V1:干预效应剖面 —— 平坦,非前置

D_JS(p^H, p^F)(top-100+tail 支撑)沿链逐位置:
[0-8) 0.050 / [8-16) 0.040 / [16-32) 0.048 / [32-64) 0.053 / [64-128) 0.041(p90 同样平坦)。

结论:视图替换对固定链分布的**压力全程均匀**;但因 prefix dominance
(margin 随 ρ 塌陷、recovery 15-20%→3%),其**因果杠杆在早期**。
修订:叙事上区分"压力处处在 / 杠杆在前";gate 逐状态计算(原设计不变),
不得引入位置先验;re-entry 窗口(事件驱动)不受影响。

### C. V2:sharpening 前提 —— 被否决,v1 删除该部件

ρ=0 答案槽上 s = H(p^F) − H(p^H) 与残差方向(margin_hide − margin_raw,指向正确为正):
corr(s, Δmargin) = −0.02;分组均值反向(s>0 组 +0.294 < s≤0 组 +0.534)。
机制:hide 更锐常意味着"自信地更错"(Perspective 镜像方向被锐化)——
原文"sharpening 不是 correctness"的警告被实测放大为轻微负相关。
各类别 slot s 均值均在 ±0.11 内,答案槽上锐化现象本身微弱。

**修订:v1 训练版移除 sharpening modifier(c_t ≡ 1),预算仅由
excess-effect gate 驱动:g_t^raw = σ((e_t − τ_e)/T_e),g_t = max(g_t^raw, ρ g_{t-1})。**
脚注:s_t 仅在 ρ=0 答案槽有方向标定,中链行为未测;训练时可记录中链 s_t
与收益的事后相关,让数据决定是否复活该部件。

### D. 经受住验证、保留的核心

1. **残差方向(以 full image 为参照)全类别为正**(hidden-response 探针联合分析:
   Perspective +0.23 / Ordering +0.12 / Contact +0.86 / Comparison +0.38 / OCR +1.04
   @ρ=0)——参照系从 null 换成 full 是本方法最关键的正确选择,
   消除了 (p^+ − p^0) 形式的类别符号问题(hide−null 在 Perspective 为 −0.96);
2. e_t 状态选择(自举于 0,随漂移打开);
3. re-entry 窗口(事件驱动);
4. state-adaptive KL budget(二分求 β_t)。

方法瘦身后的三件套:**full-参照残差重建 + excess-effect 状态选择 + re-entry 窗口**。
