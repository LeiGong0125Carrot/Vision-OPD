# 方法论 v2:去偏证据蒸馏(2026-09-03,整合 v1 负结果与 OPSA 仿写探针全部发现)

一句话:**特权教师信号是三种成分的混合物;方法 = 信号卫生栈(分离成分)× 分配策略(把净化后的证据放到信号所在的位置),全程零标签。**

09_01_plan 的三件套(full 参照残差 / e_t 门 / re-entry)保留为分配策略的一个实例;
本文档的新增层是"成分分解 + 卫生栈"——v1 训练翻车(TreeBench 全程低于 base、V* 官方口径 −13)
证明它不是可选优化,是特权 OPD 的必需器官。

---

## 1. 核心发现:特权信号的三成分分解定律

对 u_t = log p^H − log p^F(同冻结教师、特权视图 vs 全图视图、同学生前缀):

| 成分 | 统计性质 | 证据 | 处置 |
|---|---|---|---|
| **证据**(decision-relevant correction)| 稀疏、局域、集中在学生低置信 token | 答案槽残差全类别为正;gems 率随尾部深度 10→25%;去偏后答案 span 优势与对错对齐(+0.166/+0.105)| **保留并利用** |
| **偏置**(教师对输入形态的行为适应)| 稠密、逐词恒定(DC)| EOS ū+1.4(压缩)、crop 语域(inside/cropped/blurry)、场景内容压制(Looking −4.6/Stop/LEGO);v1 链长 141→72、hedge 57.8→20.0 | **逐词去均值切除** |
| **垃圾**(双低概率区 log 比值爆炸)| 极端值、集中在退化 token | 空白串 ū+8.7、中文碎片 +6.8;e^{βu} 指数放大算术 | **±4 截断** |

关键教训(v1):**探针只验证了证据成分的方向,训练积分的却是三种成分之和**——
偏置虽然逐 token 小,但稠密×全程在线,积分后压倒稀疏的证据。

## 2. 两条结构定律(跨设定复刻)

1. **信号住在学生的不确定尾部**:学生 top-20% logp token 的近零优势比例,
   OPSA 论文(纯文本数学)97.5%,我们(多模态 VQA)96.3%——跨模态常数。
   头部 token(≈80%)对任何教师都无话可说。
2. **特权优势是稠密的**:|u|≤1e-4 仅 11.8%(能力蒸馏 51.7%)——同模型异视图的教师
   从不精确沉默,每个 token 都被轻推。稠密性 × 偏置 = 结构性积分伤害;
   能力蒸馏的近零质量自我中和,没有这个病。**卫生栈因此是特权 OPD 特有的必需品。**

## 3. 信号卫生栈(三道工序,全部已实现并单测)

```
u_t  =  log p^H(y_t) − log p^F(y_t)
ũ_t  =  clip( u_t − ū[type(y_t)],  −c, +c )        # 去偏 + 截断
gate =  relu(σ((e_t−τ)/T) − σ(−τ/T)) / (1−σ(−τ/T))  # 关门归零 (门关 = 精确标准OPD)
```

- ū:逐词均值表。分布形式用逐链支撑内均值(SA-v2 已实现);
  优势形式必须用语料级 EMA(单次出现词逐链会自抵消),可用探针快照预热;
- 卫生栈的信号级验证:去偏使"正确轨迹 span 负优势"59.0%→25.3%、span 均值转正且排序正确;
  **训练级效果 = SA-v2 运行的待验证假设**(四条证伪线见 §6)。

## 4. 分配策略:同一净化信号的两个实例

**实例 A:SA-v2(在位者,已实现,待发射)** —— 分布形式
- 全 token;e_t 超额效应门(自举于 0)+ re-entry 窗 + 逐 token KL 预算二分 β;
- 目标 q = softmax(log p^H + β·ũ),JSD 蒸馏;
- 继承 09_01_plan 的状态选择主张:干预可信度随状态变化。

**实例 B:EVT(挑战者,待实现)** —— 优势形式
- 只更新学生 lowest-20% token(定律 1:信号所在;附带砍掉 80% 偏置暴露面);
- Â = clip(ũ, −2, +1)(非对称:正向保守,防 OPSA 论文实测的正优势崩溃);
- 与 OPSA 构成最小对照对(仅优势来源不同:固定负 vs 证据签名);
- 动机数:官方 compute_opsa 选中集内 18.6% 是去偏教师想抬的 token(错杀率 1/5.4);
  prefix-dominance 训练态测量(错误链 GT 词 +0.105 < 正确链 +0.166)说明
  待放大的正是"错误前缀下被压制的证据残差"——EVT 正向臂即此。

两实例正交(一个造目标,一个选 token),四臂矩阵判决后可合流(尾部限制的门控重建)。

## 6. 诊断体系(免标签,tensorboard 实时)

- **dlogp_tok_hf**(主读数):实际 token 上 H−F 每 token 似然差;起点 ≈−0.36,
  **上穿 0 = 学生被拖入 crop 教师行为盆地的警报**(v1 轨迹:−0.36→+0.05 单调上穿,伴随崩坏);
- 链长 ≥140、hedge 保有率 ≈V0(风格误伤最敏感读数)、KL≤ε 守恒、gate/e_t 曲线;
- 特权下残余搜索率(无句设定下唯一存活的词面失败标记)。

## 7. 评测协议

- TreeBench + V*,**贪心与采样(Avg@4)双口径**——增益差拆分"采样锐化效应 vs 能力本体效应"
  (预测:OPSA 增益集中在采样口径,证据蒸馏两口径同现);
- 官方 judge 口径出版数(gpt-oss;V* 上 judge 反转过 checkpoint 排序,规则口径只作横向);
- **类别指纹 = "真的在蒸馏"的证明**:增益应落在 Comparison/OCR/Contact(forcing 证据图谱),
  免教师方法无法复制该结构;
- checkpoint 加密存档(save_freq=5):迁移峰早现(V0 在 step14),近域峰晚现(V* 在 step41)。

## 8. 论文主张与证伪线

1. **特权信号必须分解**(主张):v1 负结果 = 不分解的代价(因果证据);
   SA-v2/EVT vs V0 = 分解的收益。证伪:净化臂仍不敌 V0;
2. **学生对优势方差不敏感、对优势偏置敏感**(对 OPSA 噪声主张的修正):
   其符号翻转实验动的是零均值方差;我们的三通道是恒定偏置,SGD 积分不平均;
3. **轨迹级噪声度量把救援误判为噪声**:错误轨迹中 GT 词位置的正优势(去偏后 69.8%)
   是 token 级纠错机制本身;其 40.8% 中可能同样含被误判的救援;
4. **净化特权蒸馏 > 免教师削尾**:EVT vs OPSA 最小对照对 + 类别指纹归属。
   证伪:OPSA 也复现类别结构,则特权故事需要重审。

## 9. 已知边界(诚实清单)

- Perspective 免疫核心(4B 双错 78%)不在本方法射程内,论文明说;
- 对错代理为关键词匹配,出版数需 judge 重标(768 rollouts);
- 去偏的"均匀证据"风险:若特权对某词的支持本身均匀,会被当口味切除——未探测;
- 41 步/4k 的训练量级下,所有结论待更长训练复核。
