# OPD-Aha 复刻 + Plausibility Floor 终审 (2026-09-08)

## TL;DR

自研复刻 OPD-Aha (revision_opd Eq.12/13) 两臂各 41 步 (Qwen3.5-4B, train_sa4k 同数据同预算):

- **Aha-repro (忠实复刻, β=4)**: TreeBench 负收益 (峰 46.42 ≤ base 46.91, 单调下漂至 42.72);
- **Aha+floor (我们的改进, α=0.1)**: **TreeBench 峰 48.89 @25, 超 V0 峰 48.40**, 且全程无深谷;
  V* 峰 84.82 @41 (> base 83.25, > V0 83.77)。
- **训练动力学: 两臂 41 步均零挤压** (argmax_conf 0.82→0.65 反降; OPSA 同域 16-22 步崩)
  → 重建式 (JSD 质量加权) 负压天然免疫 Ren 挤压, advantage 形式才触发。
- Floor 的净贡献 = 砍掉谷区负压后止住 repro 的下漂: 同步配对 floor 胜 7/9 点, 均值 +1.5。

## 判读

1. **忠实复刻在 TreeBench 上失败, 与官方模型行为一致**: 官方 OPD-Aha 9B 在 TB 上零迁移
   (49.63≈base 49.38, docs/官方9B终审)。论文增益在 V* 域 (短答案); TB 长推理链上,
   压语言先验/上下文 token 是负资产。
2. **Floor 把它救回来了**: 谷区 (p⁺<0.1·max) 负 u 截零后, 下漂止住 + 中期鼓包超 V0。
   证明伤害的重要来源确是谷区负压 — Ren 挤压理论在分数层面拿到正面证据
   (尽管未发生显式 argmax 挤压, 谷区负梯度仍在伤害能力)。
3. **V0 的 48.40 是早期单点, 晚期塌到 44.2**: "训练越久 TB 越差"是所有特权蒸馏臂共病,
   floor 是衰减最浅的臂。峰值对决 48.89 vs 48.40 (+0.49, 单点噪声内),
   更结实的证据是平台形态 (8 点支撑) 与配对优势 (7/9)。
4. **V* 孤峰互不复现**: repro 85.34@30 vs floor 同点 80.63; V* 相邻步波动 ±3,
   单点尖峰不可作为证据。floor V* 末段 83.77→84.82 的爬升相对可信。
5. **TB/V* 峰不同步** (floor: TB 峰@25 恰逢 V* 低谷 79.58): checkpoint 选择存在
   两基准张力, 综合最优 ≈ step30 (47.41/80.63) 或 step40 (46.17/83.77)。

## 机制注脚 (训练曲线)

- u = log p⁺ − log p⁰ 均值 ≈ −0.4: hide 特权形态的视野错配通道 (p⁺ 只见框内容,
  惩罚一切上下文 token; p⁰ 退回语言先验) 污染 u — 复刻失败的候选根因之一。
- floor 臂 clamp 比例 0.62→0.45; repro 臂谷区负压暴露 u_neg_valley_frac ≈ 0.51-0.63。
- 两臂响应长度稳定 (~235), 无 OPSA 式短确定性塌缩; base→step41 全程无循环。
